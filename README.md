# ka-js-to-html
Q: what the heck is this thing?
A: it converts your masterpiece made on khan academy to html file
Q: why is this useful?
A: in case you want to load your masterpieces as a file and send it to anyone
Q: how to use it?
A: input your khan academy code in the input box and then click the convert button and download the file (or just copy the code in the output box)
